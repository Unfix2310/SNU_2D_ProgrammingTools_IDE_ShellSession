## Introduction

The ShellSession IDE provides a robust environment for developing applications using the ShellSession programming language. With a focus on simplicity and efficiency, this IDE allows users to write, test, and debug their code in a user-friendly interface. 

This project is part of a broader initiative to enhance programming tools for 2D development, making it easier for developers to create applications that leverage the unique capabilities of 2D environments.

## Features

- **Syntax Highlighting**: Enjoy clear code visibility with syntax highlighting tailored for ShellSession.
- **Code Autocompletion**: Speed up your coding with intelligent code suggestions.
- **Integrated Debugger**: Identify and fix errors with a built-in debugging tool.
- **Customizable Interface**: Tailor the IDE to fit your workflow with various themes and layouts.
- **Version Control Integration**: Easily manage your project versions with Git integration.
- **Real-time Collaboration**: Work with team members in real-time to enhance productivity.

## Installation

To install the SNU 2D Programming Tools IDE ShellSession, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/Unfix2310/SNU_2D_ProgrammingTools_IDE_ShellSession.git
   ```

2. Navigate to the project directory:
   ```bash
   cd SNU_2D_ProgrammingTools_IDE_ShellSession
   ```

3. Install the required dependencies. Use your package manager to install any necessary libraries.

4. Run the IDE:
   ```bash
   ./start_ide.sh
   ```

## Usage

Once you have the IDE up and running, you can start a new ShellSession project:

1. **Create a New Project**: Use the "New Project" option from the File menu.
2. **Write Code**: Utilize the code editor to write your ShellSession code.
3. **Run Your Code**: Click the "Run" button to execute your program.
4. **Debugging**: Use the debugger to step through your code and inspect variables.

For detailed examples and tutorials, check the [Releases](https://github.com/Unfix2310/SNU_2D_ProgrammingTools_IDE_ShellSession/releases) section.
